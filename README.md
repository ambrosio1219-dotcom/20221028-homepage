# GUITAR GALLERY — 기타 전시관

중간고사 과제로 만든 전시 형태의 홈페이지입니다.
기타를 파는 쇼핑몰이 아니라, 기타 한 대 한 대의 **생김새와 특징, 이야기**를 보여 주는 전시관을 목표로 했습니다.

Flask(파이썬) + SQLite로 만들었고, 로그인·회원가입·게시판이 **실제 데이터베이스**에 저장됩니다.

---

## 실행 방법

```
pip install flask
python app.py
```

실행한 뒤 브라우저에서 **http://127.0.0.1:5000** 으로 접속합니다.
처음 실행하면 `gallery.db` 파일이 자동으로 만들어지고 전시물 9개가 채워집니다.

끄는 방법은 실행한 창에서 `Ctrl + C` 입니다.

---

## 화면 구성

| 주소 | 화면 | 설명 |
|------|------|------|
| `/` | 전시관 | 전시물 9개를 카드로 배열, 분류별로 거르기 |
| `/guitar/1` | 전시 상세 | 큰 사진, 소개 글, 특징 목록, 사양 표, 이전/다음 전시 |
| `/map` | 전시 위치 | 뮤직포스 매장을 기준으로 한 지도 + 지역 검색 |
| `/board` | 방명록 | 글 목록, 검색, 페이지 나누기 |
| `/board/write` | 글쓰기 | 로그인한 사람만 |
| `/board/1` | 글 보기 | 수정·삭제(본인만), 댓글 |
| `/login`, `/signup` | 로그인 / 회원가입 | 비밀번호는 암호화해서 저장 |

---

## 필수 구성 요소

1. **SNS 링크 (이미지 첨부)**
   화면 맨 아래에 인스타그램·유튜브·깃허브·페이스북·엑스·이메일 아이콘을 넣었습니다.
   아이콘 이미지는 simple-icons에서 불러오며, 주소는 각자 계정으로 바꾸면 됩니다.

2. **지도**
   구글 지도를 넣었고 **API 키가 필요 없는 방식**입니다.
   처음에는 뮤직포스 매장이 표시되고, 검색창에 지역이나 상호를 넣으면 그 위치로 지도가 움직입니다.
   `현위치(뮤직포스)` 단추를 누르면 처음 위치로 돌아옵니다.

3. **로그인 / 회원가입 (DB 연결)**
   `users` 표에 저장합니다. 비밀번호는 그대로 두지 않고 `werkzeug`로 암호화(해시)해서 넣기 때문에
   데이터베이스를 열어 봐도 원래 비밀번호는 알 수 없습니다.
   로그인 상태는 세션에 담아 두고, 로그인해야 하는 기능은 `@login_required`로 막습니다.

4. **게시판 (DB 연결)**
   `posts`, `comments` 표에 저장합니다. 글쓰기·수정·삭제·댓글·조회수·검색·페이지 나누기가 됩니다.
   **글을 쓴 사람만** 그 글을 수정하거나 지울 수 있게 확인합니다.

## 폴더 구성

```
midterm/
├── app.py              서버 프로그램 (주소별 처리, DB 만들기, 전시 자료)
├── gallery.db          SQLite 데이터베이스 (실행하면 자동 생성)
├── requirements.txt    필요한 라이브러리
├── templates/          화면 HTML
│   ├── base.html       공통 틀 (머리말, 메뉴, 꼬리말, SNS)
│   ├── index.html      전시관 첫 화면
│   ├── detail.html     전시 상세
│   ├── map.html        지도
│   ├── board.html      방명록 목록
│   ├── post_view.html  글 보기 + 댓글
│   ├── post_form.html  글쓰기 / 수정
│   ├── login.html      로그인
│   └── signup.html     회원가입
└── static/
    ├── css/style.css   전체 디자인
    ├── js/main.js      화면 연출 (스크롤하면 나타나기, 헤더, 첫 화면 조명)
    ├── js/map.js       지도 검색
    └── img/favicon.svg 탭 아이콘
```

## 데이터베이스 구조

| 표 | 내용 |
|----|------|
| `users` | 아이디, 별명, 암호화된 비밀번호, 가입일 |
| `guitars` | 이름, 브랜드, 연도, 분류, 사진 주소, 소개, 특징, 사양 |
| `posts` | 글쓴이, 제목, 내용, 조회수, 작성일 |
| `comments` | 글 번호, 쓴 사람, 내용, 작성일 |

## 참고

- 전시 사진은 위키미디어 공용(Wikimedia Commons)의 자유 이용 이미지입니다.
- SNS 아이콘은 simple-icons(CC0)를 씁니다.
- 글꼴은 구글 폰트의 Cormorant Garamond(영문 장식), Noto Serif KR, Noto Sans KR입니다.
- 사진과 글꼴, 아이콘을 불러오려면 **인터넷 연결이 필요합니다.**
